# MacPulse 同类项目对比与改进方案

> 负责人：fengjinwen ｜ 日期：2026-10-05 ｜ 对标：[exelban/Stats](https://github.com/exelban/stats)（42k+ stars）、[yujitach/MenuMeters](https://github.com/yujitach/MenuMeters)、[gaojs/eul](https://github.com/gaojs/eul)
> 结论先行：代码质量与测试覆盖已达到或超过同类开源项目，主要差距在**开源工程配套**（许可证/CI/发布/规范工具）与**主流功能体验**（菜单栏迷你图、设置窗口、开机启动、多模块）。

## 一、GitHub 工程规范对比

| 维度 | 主流同类（Stats / MenuMeters / eul） | MacPulse 现状 | 差距与动作 |
|---|---|---|---|
| 许可证 | 根目录 LICENSE（MIT 居多） | **缺失** | ✅ 本轮补 MIT LICENSE |
| CI | GitHub Actions 构建/测试 | **缺失** | ✅ 本轮补 `ci.yml`（测试+打包） |

| 代码规范工具 | Stats 有 `.swiftlint.yml` | 无 | ✅ 本轮补 `.swiftlint.yml` |
| 提交规范 | Stats/MenuMeters 提交信息较随意 | **Conventional Commits 全程遵守**（领先） | 保持 |
| 测试 | 均有测试目录 | 241 断言 + 集成/实采对照（覆盖较好） | 保持并随功能增长 |

| 构建体系 | xcodeproj / SPM | `swiftc` 脚本（本机无完整 Xcode 的务实选择） | 保持并记录；长期可 SPM 化 |
| 贡献策略 | Stats "open source, not open contribution" | 无 CONTRIBUTING | 🔜 路线图（个人项目可暂缓） |

## 三、改进方案

### A. 本轮落地（工程规范 + 主流体验快速项）
1. `LICENSE`（MIT）。
2. `.github/workflows/ci.yml`：push/PR 自动运行核心测试、进程对照与打包。
3. `.swiftlint.yml`：mainstream 规范工具配置。
4. `Scripts/make-dmg.sh`：生成 `dist/MacPulse.dmg` 发布产物。
5. **开机启动开关**：`SMAppService`（macOS 13+ 原生 API），弹层开关 + 右键菜单状态项。
6. `README.md`：徽章、功能表、License 章节。
7. 版本 tag：`v1.0.0`（与 bundle 版本一致）。

### B. 短期路线（下一版本）
1. 设置窗口（SwiftUI Settings 场景）：模块启停、更新间隔、外观。
2. 菜单栏内嵌迷你图（可开关，替代纯文本）。
3. 英文本地化（`Localizable.xcstrings`），随后开放社区翻译。
4. DMG 附到 GitHub Release（Actions 发布 job）+ 自建 Homebrew tap。

### C. 长期路线
1. SMC 传感器 / GPU / 电池 / 风扇模块（含能耗取舍，参考 Stats 默认关闭策略）。
2. WidgetKit 桌面小组件。
3. Sparkle 更新与公证签名。
4. 模块化进一步演进：每分类独立菜单栏项（对齐 Stats 交互模型）。
