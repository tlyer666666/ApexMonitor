# MacPulse

一款原生 macOS 菜单栏性能监控器，快速查看 CPU、内存、磁盘读写和网络收发状态。

## 功能

- 菜单栏持续显示 CPU 总使用率。
- 点击菜单栏项目查看 CPU、内存占用、磁盘读写速率和网络收发速率。
- 打开完整仪表盘查看同一份实时数据与历史统计。
- 仪表盘支持 5分钟 / 15分钟 / 30分钟 / 1小时 / 24小时 / 7天 时间范围，展示各指标趋势图与“平均 / 峰值”统计摘要；短周期（≤1小时）优先显示逐秒明细，更长周期显示分钟级均值。
- 本机保留最近 7 天的分钟级历史（含均值与峰值），跨分钟自动聚合，每 5 分钟落盘一次，退出时保存未完成的分钟。
- 约每秒刷新；系统指标读取和计算在低优先级后台队列执行。
- 原生 SwiftUI/AppKit 界面，无第三方运行时依赖。

## 构建与运行

要求 macOS 13 或更新版本、Apple Swift 编译器和对应 macOS SDK。无需管理员权限。项目使用直接调用 `swiftc` 的构建和测试脚本；不依赖 Swift Package Manager 或第三方运行时。

```sh
# 编译 Debug 可执行文件
Scripts/build.sh debug

# 生成菜单栏应用包
Scripts/package-app.sh

# 启动应用
open dist/MacPulse.app

# 运行纯 Swift 指标计算测试
Scripts/test.sh

# 烟测真实系统计数器（CPU/内存/磁盘/网络接口）
Scripts/smoke.sh
```

产物路径：`dist/MacPulse.app`。关闭主仪表盘窗口不会退出菜单栏应用；使用弹层中的“退出 MacPulse”结束程序。

## 权限、隐私与数据边界

- 不需要管理员/root 权限，不安装 helper 或系统扩展。
- 不建立网络连接、不上传数据、不包含遥测。
- 性能历史以分钟桶（均值/峰值）保存在本机 `~/Library/Application Support/MacPulse/history-v1.json`，仅用于本机展示；保留 7 天后自动剪枝；删除该文件即清空历史。
- 逐秒明细只保存在进程内存（最近约 2 小时），不写盘。
- 应用不默认注册为开机启动项。

## 指标说明与限制

- CPU 百分比由相邻主机处理器 tick 样本计算；第一次采样用于建立基线，随后显示有效读数。
- 内存占用按 active、wired 和压缩器页统计，并以物理内存作为总量。
- 磁盘数据汇总当前可访问 IOKit block storage 服务的累计字节计数；不做进程级或卷级归因。某些设备/虚拟化环境不提供这些计数时显示“—”。
- 网络数据逐一累加非 loopback 接口本次运行内的收发字节增量，不区分进程、VPN 或物理路径；macOS 接口统计以 32 位计数提供，应用按接口识别计数回绕；新接口加入先建立基线，避免显示历史流量尖峰。
- 历史统计为分钟级均值/峰值：5–30 分钟范围在逐秒样本足够时显示逐秒曲线，否则退回分钟桶；重启后短周期由分钟桶补充，数据点较粗。
- 首次建立基线或计数器回退/采样间隔无效时，速率显示“采集中”或“—”，不会伪造零值。

## 本机验证环境

本项目在 macOS 27.0、Apple Swift 6.3.3（arm64）和 Command Line Tools SDK 环境构建。该环境没有完整 Xcode，且 SwiftPM manifest 链接和 XCTest/Swift Testing 模块不可用；`Scripts/build.sh` 和 `Scripts/test.sh` 因此使用 `swiftc` 直接编译。应用 bundle 本地构建成功，但未签名；若 Gatekeeper 拦截，请在本机开发环境自行签名或从源码运行。
