# MacPulse 结构与稳定性审查交付

> 负责人：fengjinwen ｜ 日期：2026-09-30 ｜ MPC004

## 结论

按独立问题域完成定向审查、结构拆分和可复现缺陷修复，不以“原有测试全绿”作为统计或生命周期正确的替代证明。定向审查以真实夹具复现了进程漏采、历史流量放大、异步过期结果回写、时钟回拨丢历史等问题，全部修复并附回归测试。

## 审核问题与处理

| 问题 | 复现证据 | 处理 |
|---|---|---|
| 进程枚举单位错误 | libproc 传 PID 槽数而非字节，原实采约135条；独立枚举可读445条 | 按字节容量传参，满缓冲扩容；TASKALLINFO一次读取名称、启动身份、CPU/RSS |
| PID复用误算 CPU | 同PID/名称、启动时间变更但CPU计数更大，旧版仍报40% | PID+秒/微秒启动身份绑定，变更即重建基线 |
| 关详情后旧结果回写 | 阻塞主线程直到后台读完，再关闭详情，旧版仍发布summary | 独立DetailSampler，代次校验后才在MainActor发布 |
| 主采样取消/重启脏结果 | 已排队回调可能越过stop | 主线程管理定时器生命周期，后台worker按start隔离，发布代次屏障 |
| 部分分钟流量被放大 | 1秒100 B/s被算成6000 B/60秒；59个nil+1个有效样本同样失真 | 保存实际有效时长、每指标计数、字节积分；图表均值与总量分离 |
| 重启碎片加权错误 | `[nil,100] + [0]`平均66.67而不是50 | 每指标按有效count/sum合并，nil不增加分母 |
| 历史峰值丢失 | 单分钟一次6000 B/s，其余0，旧UI峰值变成均值100 | 汇总峰值从元数据samplePeak取，图表仍画均值 |
| 即时与重启后统计不一致 | 同一分种的两个片段查询前未合并 | HistoryRecorder统一实时插入/flush/查询，规范化一分种一桶 |
| 时钟回拨删除历史 | 111+222+333应666，回拨后仅555；保存可直接清空未来桶 | 存储保留与查询过滤分离；暂时future只隐藏不删，时钟恢复可见 |
| 混合粒度错误均值 | 60秒0%、60秒100%，混合序列报98.36%，重启后50% | 汇总按每指标有效样本数加权，前后均50% |
| 文件损坏静默覆盖 | 读取/解析失败当空历史继续保存 | 文件读取错误保留原件，展示警告；限制文件体积、桶数和无效数值 |
| 桌面快捷方式覆盖普通文件 | 隔离HOME里同名文本被ln -sfn替换 | 拒绝普通文件/无关链接/无关应用；staging校验后更新，失败回滚 |
| 有限大百分比转换崩溃 | percent(1e20)的Double→Int触发陷阱 | 使用Int(exactly:)与非负校验，保留合法多核>100% |
| 每秒变化的按钮身份 | GUI点击内存按钮因标题改变无法定位 | 固定分类accessibilityLabel，读数放到accessibilityValue |

## 结构优化

- `Sources/MacPulseApp/Monitoring/MonitorStore.swift`：只协调生命周期与可观察UI状态，不直接拥有采样worker、分钟聚合或磁盘队列。
- `.../DetailSampler.swift`：独立明细采样会话、代次取消、单调uptime进程基线；注入Reader以精确控制竞态测试。
- `.../MetricsSampler.swift`：系统采样与接口总量一次交付；长采样间隙重新建基线。
- `.../HistoryRepository.swift`：串行I/O，固定磁盘基线+当前运行快照，避免重复合并自身输出及提前退出覆盖；保存失败可反馈。
- `Sources/MacPulseCore/HistoryRecorder.swift`：完成/部分分钟统一插入、保留期、窗口查询与分辨率组合。
- `.../MetricsHistory.swift`：为旧JSON兼容新增有效计数/时长/积分/峰值元数据，单独区分未知旧数据和边界估算。
- `.../HistoryValidation.swift`：集中校验磁盘载入的数值边界。
- `Tests/MacPulseIntegrationTests/`：采样取消、快速分类切换、对象释放、早退保存、保存队列、时钟回拨、混合粒度、损坏文件等测试。
- `Tests/Scripts/install_test.py`：在临时HOME里执行实际安装脚本（打包步骤用既有测试bundle），不触碰真实桌面。
- `Scripts/integration-test.sh`、`Scripts/process-test.sh`：提供可重跑集成与实采完整性验证入口。

## 请求到证据的完成审计

- **审核代码**：按独立问题域（历史/持久化、进程采集/安装、视图层/跨层）分别审查，均给出真实夹具而非泛泛风格建议；时钟回拨与混合均值两项以RED→GREEN修复。
- **优化结构**：Store拆分为DetailSampler / HistoryRecorder / HistoryRepository；当前Store约150行，原版约270行。网络详情消费独立流量序列而非拿图表均值推总量。
- **提高稳定性**：每项上表的回归证据与新测试文件相对应；取消、重启、退出、损坏数据、安装冲突均纳入自动验证。
- **交付**：源码、测试脚本、README、本文及计划随项目提交；可运行包 `dist/MacPulse.app`。

## 已知限制（不夸称全部解决）

1. 现有网络读取仍使用getifaddrs的32位计数，近90%→低10%的回绕启发式在高速链路或多次回绕时可能漏算。目标机NET_RT_IFLIST2亦曾返回被截断的数值，未经充分实测的64位方案未替换进生产。该问题已列入审查，不承诺计费级准确流量。
2. 旧版本历史没有有效时长，不可能恢复精确字节总量：保留均值/峰值，未知覆盖的流量不合计；UI显示缺口。跨分钟边界裁切按比例估算并明确标识。
3. GUI验证不等于长期压力测试。没有进行真实系统睡眠/改系统时钟/连续运行7天，而是使用确定性时间夹具覆盖逻辑；菜单栏右键菜单为系统菜单交互，未纳入自动化点击验收。
4. macOS 13是编译目标，本机macOS 27/arm64完成验证，未声称在Intel或所有macOS版本上实机测试。
