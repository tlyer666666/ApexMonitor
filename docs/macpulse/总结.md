# MacPulse 项目总结

> 负责人：fengjinwen ｜ 更新日期：2026-09-30

## 一、项目概述

MacPulse 是一款原生 macOS 菜单栏性能监控器：菜单栏常驻显示 CPU 总使用率，点击弹出快捷状态层（各分类可直达详情页），并提供完整仪表盘——支持 5分钟/15分钟/30分钟/1小时/24小时/7天 时间范围的趋势图与统计摘要。约每秒刷新，采样与计算在低优先级后台队列执行；本机保留 7 天分钟级历史；不需要管理员权限，不联网，无第三方运行时依赖。

## 二、交付文件（模块清单）

- `Sources/MacPulseCore/MetricTypes.swift` — 原始样本与快照值类型（含采样有效时长、CPU 分解百分比）
- `Sources/MacPulseCore/MetricsCalculator.swift` — CPU 分解、速率计算；计数器重置、零时间差与长间隙重建基线保护
- `Sources/MacPulseCore/MetricsFormatter.swift` — 百分比、字节、速率、时长与内存摘要格式化（全部防陷阱转换）

## 三、关键设计

- **采样与计算分层**：系统 API 读取（Mach/IOKit/getifaddrs/libproc）与纯计算（`MetricsCalculator`/`ProcessTable`/`HistoryAnalyzer`）严格分离，后者全部可确定性测试。
- **不伪造数据**：首样本、计数器回退、PID 复用、无效时间间隔、缺失计数器一律显示"—/采集中"，不产生伪零或负速率。
- **历史统计口径**：分钟桶持久化每指标的有效样本数、有效时长、速率积分与采样峰值；部分分钟不放大成 60 秒，缺失值不参与平均，图表均值与流量总量分离，旧数据缺口如实标注。
- **网络计数**：接口计数为 32 位，逐接口展开回绕后合计；运行期增量口径，新接口先建基线，不显示历史流量尖峰。
- **生命周期所有权**：`DetailSampler`/`MetricsSampler` 采用代次校验取消，过期结果不回写主线程状态；`HistoryRepository` 串行 I/O + 固定磁盘基线，提前退出不会用空数据覆盖历史。
- **界面设计令牌**：`DesignSystem` 统一间距/圆角/图表尺寸与分类语义色；分类卡、图表卡、弹层行全部由 `MetricCategory` 单一来源驱动；交互控件带悬停反馈与稳定辅助功能标签。

## 四、关键缺陷修复说明

| 缺陷 | 修复 |
|---|---|
| Mach 端口权限泄漏导致长时间运行后采样失效 | `mach_host_self()` 配对 `mach_port_deallocate` |
| 进程枚举把 PID 槽数当字节数，漏采约 75% 进程 | 按字节容量传参，满缓冲扩容，估算竞态重试 |
| PID 复用后 CPU 占用误算 | 绑定进程启动时间身份，变更即重建基线 |
| 部分分钟流量放大成完整 60 秒 | 持久化有效时长与字节积分，按真实覆盖累计 |
| 缺失样本扭曲均值且合并顺序相关 | 每指标按有效样本数加权合并，顺序无关 |
| 历史峰值退化为分钟均值 | 峰值取自持久化的采样峰值，图表仍绘制均值 |
| 图表只画最近约 10 小时（截断） | 均匀降采样并固定最新点在右缘 |
| 网络回绕启发式可伪造流量尖峰 | 回绕处理收敛到逐接口累加器，运行期总量单调 |
| 时钟回拨永久删除历史 | 存储保留与查询过滤分离，暂时"未来"数据只隐藏 |
| 损坏/异常历史被空数据覆盖 | 读取校验数值边界，失败保留原件并提示 |
| 关闭详情页后过期结果回写界面 | 采样会话代次取消，过期发布直接丢弃 |
| 弹层固定高度裁切退出按钮 | 高度由内容自适应 |
| 双击分类卡全部跳转内存详情 | 分类导航由 `MetricCategory` 驱动 |
| 极大百分比触发整数转换崩溃 | `Int(exactly:)` + 非负校验 |
| 安装器可能覆盖桌面文档或无关应用 | 目标守卫 + staging 校验 + 失败回滚 |
| 菜单栏图标缺少退出入口 | 左键弹层、右键菜单（打开主面板 / 退出 MacPulse） |

## 六、已知限制

1. 网络接口计数为系统提供的 32 位值：回绕启发式在高速链路或多次回绕时可能漏算，不承诺计费级准确流量。
2. 无有效时长元数据的旧历史可查看均值/峰值，但无法还原精确流量总量；跨时间边界的桶按比例估算并明确标识。
3. 已通过确定性时间夹具覆盖时钟回拨与长间隙逻辑，未做真实睡眠/连续 7 天运行的压力测试。
4. 目标 macOS 13+（arm64 实测）；应用未签名，首次打开可能需右键"打开"或自行签名。
