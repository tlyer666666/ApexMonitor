# MacPulse 系统性能监控器（MPC001）· 计划

> 父需求：macOS 轻量系统性能监控器 ｜ 负责人：fengjinwen  
> 依赖：macOS 原生系统指标接口；无外部服务、数据库或第三方运行库依赖。  
> v1.1 追加（2026-09-28，用户指示）：仪表盘补充过去数天的流量/CPU 等历史数据与 5 分钟/15 分钟/30 分钟等粒度统计，优化 UI 信息层次。默认决策：本机保留 7 天分钟级历史（均值/峰值），存储于 `~/Library/Application Support/MacPulse/`，范围提供 5分钟/15分钟/30分钟/1小时/24小时/7天。

## 目标

用户可通过菜单栏快速查看当前 CPU 使用率，并在弹层或仪表盘持续查看 CPU、内存、磁盘读写和网络收发状态；仪表盘可切换时间范围查看历史趋势与统计摘要。应用在约 1 秒间隔更新，常驻低开销，不需要管理员权限，不联网。

## 验收标准

- [ ] 应用有明确的 macOS app bundle 与构建/启动说明；启动后只以菜单栏形式常驻，不显示 Dock 图标。
- [ ] 菜单栏图标显示 CPU 百分比；点击可显示弹层，再次点击或执行关闭操作可隐藏。
- [ ] 弹层提供 CPU、内存占用/百分比、磁盘读写速率、网络接收/发送速率及打开仪表盘和退出操作。
- [ ] 仪表盘展示同一份指标快照及最多 60 秒内存趋势；窗口关闭不停止采样。
- [ ] 初次采样、采样失败、累计计数器回退和无效时间间隔均不会制造伪零或负速率。
- [ ] 指标计算与格式化逻辑由自动测试覆盖；可用工具链下构建和测试通过。
- [ ] 提供运行、构建、权限/隐私边界与已知限制说明。

## 任务拆解

1. **指标采集与快照**（`MetricsProvider`、`MetricsSampler`、`MonitorStore`）：应用按约 1 秒间隔读取系统累计计数器和瞬时值，汇聚为一份供所有 UI 消费的快照。
   - 实现要点：为首次采样和不可用字段建模；将系统 API 读取与纯计算分层；非 UI 队列采样；可取消。
2. **指标计算与单元测试**（`MetricsCalculator`、指标格式化）：利用相邻样本计算 CPU 百分比及字节/秒速率，处理计数回退、时间间隔异常与单位转换。
   - 实现要点：注入原始样本和时间戳使逻辑可确定性测试；趋势上限 60 点。
3. **菜单栏与监控界面**（状态栏控制器、SwiftUI 弹层与仪表盘）：展示同一快照，支持快捷查看、完整窗口、退出。
   - 实现要点：无 Dock 菜单栏 app、原生自适应外观、清晰单位与指标不可用占位。
4. **构建与交付**（bundle、脚本、README、开发总结）：提供可重复构建和启动的 app 交付件及验证说明。
   - 实现要点：探测 Command Line Tools 的实际能力；如受限，清晰标注可验证范围和构建前置条件。

## 边界 / 依赖

- **不做的事（作用域外）**：进程排行、告警、网络/云端、遥测、登录、开机启动、管理员 helper、安装器与自动更新、导出。
- **外部依赖**：Swift、macOS SDK、macOS 系统公开指标 API；测试可运行在 Swift Package Manager。
- **需要配合的事项**：实际启动 app 需要 macOS GUI 会话；本机没有完整 Xcode，必须记录命令行工具链限制。

# 分类详情面板（MPC002）· 计划（v1.2 追加，2026-09-28）

> 父需求：MacPulse ｜ 负责人：fengjinwen
> 依赖：既有 MetricsSampler/MonitorStore 数据流；libproc、Network.framework、FileManager 卷容量均为系统公开接口，无新权限。

## 目标

用户点击主界面的分类卡片（CPU/内存/磁盘/网络）进入对应详情页，查看该分类的详尽实时数据：内存显示使用率、可用容量与进程占用 Top；磁盘显示读写速度、剩余空间与挂载卷容量；网络显示实时流量、在线状态与接口明细；CPU 显示总使用率、user/system/idle/nice 分解、负载均值与进程占用 Top。常驻开销保持低位。

## 验收标准

- [ ] 主界面四张分类卡片可点击进入详情页，详情页可返回主界面；关闭重开面板后导航状态随之重建。
- [ ] 内存详情显示：使用率、已用/可用/总量、压缩器内存与交换累计；进程占用列表（进程名、内存、CPU%）按内存排序，约 2 秒刷新，仅详情页打开时采样。
- [ ] 磁盘详情显示：读/写速率、根卷已用/可用/总量百分比、已挂载卷容量列表。
- [ ] 网络详情显示：收/发实时速率、本次运行累计、在线状态（在线/离线与接口类型）、每接口 UP/RUNNING 状态、IP 地址与运行期收发累计。
- [ ] CPU 详情显示：总使用率、user/system/idle/nice 百分比、1/5/15 分钟负载均值、按 CPU 占用 Top 进程（含内存列）。
- [ ] 任何明细读取失败时显示"—"/"暂不可用"，不伪造数据；详情页关闭后采样停止。
- [ ] 纯逻辑（CPU 分解、进程表增量/排序、每接口运行期总量）由自动测试覆盖；`Scripts/test.sh` 全绿；`Scripts/smoke.sh` 通过；打包脚本产出 `MacPulse.app`。

## 任务拆解

1. **CPU 分解百分比**（`MetricsCalculator`/`MetricTypes`）：快照新增 user/system/idle/nice 百分比（由累计 tick 差计算，首样本/异常间隔为 nil）。
   - 实现要点：复用既有 tick 差值逻辑，各状态占比 = 状态增量 / 总增量 × 100。
2. **进程占用计算**（`ProcessTable` 纯逻辑 + `ProcessSampler` 系统读取）：以相邻两次样本的 CPU 时间差与内存驻留量生成按 CPU/内存排序的 Top 列表。
   - 实现要点：CPU% = ΔCPU 时间(ns) / (Δ墙钟(s) × 10⁹) × 100；进程消失即剔除、新进程首样本无 CPU%；libproc 枚举同用户进程，无需新权限。
3. **卷容量读取**（`VolumeSpaceReader`）：根卷与已挂载卷的总容量/可用空间。
   - 实现要点：FileManager 卷资源键；读取失败该卷显示不可用。
4. **网络在线状态与接口明细**（`NetworkPathMonitor` + `SystemMetricsReader`/`NetworkCounterAccumulator`）：路径监视发布在线状态与接口类型；getifaddrs 提供每接口 UP/RUNNING、IP 地址；累加器暴露每接口运行期收发累计。
   - 实现要点：NWPathMonitor 事件驱动零轮询；接口明细随秒级采样复用。
5. **导航与详情视图**（`DashboardView`/`CategoryDetailView` 等）：卡片成为导航入口，四个详情页按"总览数值 → 细分明细 → 列表"层级展示；`MonitorStore` 提供按需开/关明细采样。
   - 实现要点：NavigationStack + 可哈希分类枚举；详情页 onAppear 开采样、onDisappear 停采样。
6. **自测与交付**：`Scripts/test.sh`、`Scripts/smoke.sh`、打包、GUI 验收（辅助功能树验证详情页元素与返回导航）、更新 README/总结并推送 GitHub。

## 边界 / 依赖

- **不做的事（作用域外）**：每进程网络流量、磁盘每进程 I/O、TCP 连接逐条列表、Wi-Fi SSID（需定位权限）、GPU/传感器、历史数据落盘扩展。
- **外部依赖**：libproc、Network.framework、Foundation 卷资源键（均系统公开接口）。
- **需要配合的事项**：无。

## 待确认

- 无阻塞项；视觉细节按原生风格取舍。

# 弹层直达与分时段流量统计（MPC003）· 计划（v1.3 追加，2026-09-29）

> 父需求：MacPulse ｜ 负责人：fengjinwen
> 依赖：既有 MonitorStore 导航路径、HistoryRange 与分钟桶/逐秒序列（v1.1/v1.2）。

## 目标
用户在菜单栏弹层中点击任意指标项即可直达对应详情页；网络等详情页除连接状态外，还提供按时间段的流量统计明细（总接收/发送流量、峰值速率、统计覆盖时长）。

## 验收标准
- [ ] 弹层中四个指标行可点击，点击后面板打开并直接落在对应详情页；"打开监控面板"仍进总览；"退出"不变。
- [ ] 网络详情页提供时间段选择（5分钟/15分钟/30分钟/1小时/24小时/7天）与流量统计卡片：接收/发送总流量、双向峰值速率、统计覆盖时长。
- [ ] 总流量由速率按采样间距积分（逐秒 ×1s、分钟桶 ×60s）；缺失样本不计入；覆盖不足时显示真实覆盖时长，不外推。
- [ ] 积分统计与时长格式化由自动测试覆盖；`Scripts/test.sh` 全绿；打包/安装脚本可用。

## 任务拆解
1. **流量统计核心**（`HistoryAnalyzer.trafficStatistics` + `MetricsFormatter.duration`）：积分求和、峰值、覆盖时长；纯逻辑 TDD。
2. **序列暴露**（`MonitorStore.series(for:)`）：返回点位与采样间距（逐秒 1s / 分钟桶 60s），供图表与统计共用。
3. **网络详情流量卡片**：时间段选择 + 总量/峰值/覆盖展示。
4. **弹层直达**（`MenuPopoverView` + `AppDelegate`）：指标行变按钮，点击关闭弹层、打开面板并导航到对应分类。

## 边界 / 依赖
- **不做的事**：跨会话流量累计（应用未运行时段不外推）、按进程/按接口分时段统计、告警。
- **外部依赖**：无新增。
