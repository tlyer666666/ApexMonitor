# MacPulse

原生 macOS 菜单栏性能监控器。菜单栏常驻显示 CPU 使用率，点开就能看到 CPU、内存、磁盘读写和网络收发的实时状态与历史趋势。数据全部来自系统公开接口，无第三方依赖，不联网，不需要管理员权限。

## 功能

- 菜单栏图标显示 CPU 总使用率；左键弹出快捷状态层，右键打开菜单（打开主面板 / 退出）。
- 弹层列出 CPU、内存、磁盘、网络四项当前读数，点击任意一行直接进入对应详情页。
- 仪表盘展示同一份实时数据，时间范围支持 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 24 小时 / 7 天，附各指标均值与峰值。1 小时以内的范围显示逐秒明细，更长范围显示分钟均值。
- 详情页提供分解数据：CPU 的 user/system/idle/nice 与负载均值、内存的压缩器与交换占用、磁盘的挂载卷容量、网络的接口状态与分时段流量统计。
- 历史以分钟桶保存在本机，保留 7 天；约每秒刷新，采样和计算在低优先级后台队列执行。

## 构建与运行

需要 macOS 13 或更新版本（Apple Silicon）、Apple Swift 编译器和对应 SDK。不需要管理员权限，也不依赖 Swift Package Manager。

```sh
Scripts/build.sh debug       # 编译 Debug 可执行文件
Scripts/package-app.sh       # 生成 dist/MacPulse.app（含程序化生成的图标）
Scripts/install.sh           # 安装到 ~/Applications 并创建桌面快捷方式，重跑即可更新
open dist/MacPulse.app       # 启动

Scripts/test.sh              # 指标计算与历史逻辑测试
Scripts/integration-test.sh  # 采样取消/切换、历史读写、时钟回拨、安装保护
Scripts/process-test.sh      # libproc 枚举与进程数据对照
Scripts/smoke.sh             # 真实系统计数器烟测
Scripts/gui-harness.sh       # 用隔离的历史目录运行 GUI 实例
```

启动后直接显示主面板；关闭窗口只是收起，应用继续在菜单栏运行，双击桌面快捷方式或从弹层重新打开。菜单栏图标：左键弹层，右键菜单，⌘Q 退出。产物未签名，首次打开如被 Gatekeeper 拦截，在「系统设置 → 隐私与安全性」中放行，或自行签名。

## 隐私与数据

- 不请求管理员权限，不安装 helper 或系统扩展，不建立网络连接，不包含遥测，也不会把自己注册为开机启动项。
- 历史保存在 `~/Library/Application Support/MacPulse/history-v1.json`，7 天后自动剪枝，删除该文件即清空。逐秒明细只存在内存中（最近约 2 小时），不写盘。

## 指标口径与限制

- CPU 百分比由相邻两次处理器 tick 计算，首次采样只用于建立基线。
- 内存占用按 active + wired + 压缩器页统计，总量取物理内存。
- 磁盘统计 IOKit block storage 的累计字节数，不做进程级或卷级归因；系统不提供计数时显示「—」。
- 网络按接口累加本次运行内的收发字节增量，不区分进程、VPN 或物理路径。接口计数是 32 位，应用按接口识别回绕；新接口先建立基线，避免显示历史流量尖峰。
- 历史分钟桶保存每个指标的有效样本数与有效时长：部分分钟不会按 60 秒放大，缺失样本不参与平均。旧版本历史没有时长元数据，界面只合计可核算的部分并标明缺口，原文件保留不动。
- 时钟回拨时处于「未来」的数据只暂时隐藏，不删除；历史文件损坏时保留原文件并显示警告，不会用空数据覆盖。
- 进程列表只包含当前权限可读的进程；用 PID 加进程启动时间确认身份，PID 复用后重新建立基线。
- 建立基线或计数器回退期间，速率显示「采集中」或「—」，不会用零值填充。

## 开发说明

开发环境只装了 Command Line Tools，没有完整 Xcode，SwiftPM 和 XCTest 不可用，因此构建与测试脚本直接调用 `swiftc` 编译（见 `Scripts/`）。装有完整 Xcode 的环境同样可以运行这些脚本。

模块划分、数据采集口径和历史存储格式见 [docs/architecture.md](docs/architecture.md)。
