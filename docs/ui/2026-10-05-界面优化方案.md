# MacPulse 界面优化方案（v2 UI）

> 负责人：fengjinwen ｜ 日期：2026-10-05 ｜ 范围：弹层、总览仪表盘、四个详情页
> 原则：信息密度服务于"一眼读懂"；同一语义只用一种表达；所有交互控件有明确可供性；深浅色与 Dynamic Type 一等公民。

## 一、设计令牌（新增 `Views/DesignSystem.swift`）

### 语义色（单一事实来源 = MetricCategory）
- CPU `.blue`、内存 `.purple`、磁盘 `.orange`、网络 `.green`。
- 状态色：在线 `.green`、离线 `.red`、警告（历史读取失败）`.orange`。
- 禁止视图像素级硬编码色值；卡片图标底色 = tint.opacity(0.12)。

### 尺寸
- 圆角：卡片 16、内嵌元素 8、芯片 Capsule。
- 间距：页面 20 / 卡片内 16 / 行内 8–12；图表高度 110。
- 数字列宽：内存 84、CPU 56（用 minWidth 保留 Dynamic Type 缩放）。

### 字体
- 页面标题 `.largeTitle rounded bold`；卡片标题 `.headline secondary`；
- 指标值 `.title3/.body rounded semibold monospacedDigit`；辅助 `.caption/.caption2`。

## 二、总览仪表盘

1. **头部**：增加"最后更新 HH:mm:ss"（来自 snapshot 时间），与"每秒更新"绿点并列。
2. **分类卡片**：标题/图标/颜色全部改用 `MetricCategory`，消除字面量重复；卡片语义统一为"分类名 + 主指标"：
   - CPU → 总使用率；内存 → 占用率（副行 已用/总量）；磁盘 → 读+写（副行保留）；网络 → 收+发（副行保留）。
   - hover 时卡片底色 `tint.opacity(0.08)`，提供可点击反馈。
3. **图表卡**：数值全 nil 时显示空态（波形图标 + "正在建立基线…"）；双序列图例保留；"峰值≈"沿用估算标记。
4. **底栏**：历史读取失败时显示可读警告；正常时显示范围与保留期说明。

## 三、菜单栏弹层

1. 移除固定 `contentSize` 高度，仅保留宽度 320，按内容自适应，避免加入迷你趋势后裁切。
2. 四个指标行：hover 高亮 + 右箭头（已有）；内存行改用 `MetricsFormatter.percent` 统一格式。
3. CPU 迷你趋势保留，高度收紧至 20，视觉上归属于 CPU 行。
4. 头部副标题统一为"点击分类查看详情"。

## 四、详情页

1. 每页新增**主卡**：大号当前值 + 语义进度条/双向速率，作为页面锚点。
2. 抽取共享 `ProcessListHeader`（内存页与 CPU 页复用），进程行保持"序号/名称/内存/CPU"。
3. 空态统一：图标 + "采集中…"；读取失败显示"暂不可用"而非静默空白。
4. 网络页估算提示与图表"峰值≈"标记保持同一措辞来源。
5. 各页头部顺序统一：主卡 → 分解/明细卡 → 列表卡。

## 五、交互流程

- Esc/返回总览（已有）不变；详情页间不做横向切换，保持"总览为枢纽"的简单模型。
- 分类点击重复触发幂等（push 同分类仅一次）；弹层点击分类后面板直达对应详情（已有）。
- 关闭窗口：停明细采样、回总览（已有），重开保留时间范围（已有）。

## 六、可访问性

- 四个分类按钮已有稳定 label/value；进程行、接口行补充 label 聚合（名称+数值）。
- 保留 monospacedDigit 数字列；Dynamic Type 下最小宽度不截断语义。

## 七、验收

- gui-harness 隔离实例截图：浅色/深色下总览、内存详情、网络详情。
- 既有 241+26 项测试不回退；弹层与详情无裁切；四按钮可被稳定辅助功能定位。

## 八、实施记录（2026-10-05）

- 新增 `Views/DesignSystem.swift`：Spacing/CornerRadius/Chart 令牌、`MetricCategory` 扩展（headline/secondary/currentValue/pointKeyPath）、`HoverableCard`、`CollectingPlaceholder`。
- 总览：分类卡由 `MetricCategory` 驱动（修复四卡片全部跳内存页的 P1 回归）；卡片加 hover 高亮与稳定辅助功能标签；头部显示真实更新时间（刚刚/X 秒前，停滞转橙）。
- 弹层：四个分类行统一由 `MetricCategory` 驱动，每行附分类色迷你趋势（隐藏自辅助功能），行聚合朗读；高度自适应不再裁切；内存改用统一百分比格式。
- 详情页：抽共享 `ProcessListHeader`；固定列宽改 `minWidth` 支持 Dynamic Type；网络页峰值在估算时显示"峰值≈"；文案统一为"采集中…"。
- 窗口最小尺寸与 SwiftUI 最小帧对齐为 780×680；`trafficRange` 上移至 Store。
- 既有 241 核心断言与 26 项集成检查通过；隔离 GUI 验收确认导航、进程列表（398 个当前权限可读）与实时 CPU% 正常。
